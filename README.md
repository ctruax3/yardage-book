# The Crown Yardage Book

A mobile-friendly yardage book and 3D course view for The Crown Golf Club, Traverse City, Michigan.

Open `index.html` (or the GitHub Pages URL) in a phone or desktop browser.

## Data sources
- Course features: © OpenStreetMap contributors (ODbL)
- Trees, buildings and 1 m ground: 2015 FEMA/NOAA Michigan LiDAR, Grand Traverse County (public domain)
- Elevation: USGS 3DEP (public domain)
- Scorecard yardages: GolfPass

Distances are estimates from public GIS data; check them on the course.
